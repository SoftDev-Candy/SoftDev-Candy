## 🛰️ [GuardianSAR](https://github.com/SoftDev-Candy/GeoSpace_Defence_AI)

> **Machine Learning • Computer Vision • Defence / SAR Analysis**

An explainable SAR image-classification project built around 5,744 public MSTAR images across 11 classes. The current pipeline extracts image metadata, validates dataset quality, analyses class imbalance, and documents shortcut-learning risks before model development. My plan with this project as I keep progressing into my data and machine learning journey is to make it into a defence style image recognition project which would help the targeting system better acquire and identify target. Eventually I plan to use Unreal Engine as a simulation tool to try and test my AI and algorithm and get a better training environment for it any feedback is appreciated and would love to hear your thoughts !
